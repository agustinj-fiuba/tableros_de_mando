### Archivos a tener en cuenta

- El main_automatico contiene el sketch de arduino para el ciclado automatico al presionar el pulsador o el pedal, se presiona una vez y empieza a ciclar indefinidamente
- El main_ciclado contiene el sketch de arduino para un ciclado al presionar el pulsador o el pedal, se debe presionar cada vez que se quiere hacer un ciclo
- El resto de archivos se descartan, son pruebas
